# ภาพรวมโปรเจกต์

โปรเจกต์นี้ใช้ปรับ tag ของ Azure Virtual Machines ให้ตรงกับข้อมูลที่ผู้รับผิดชอบยืนยัน เริ่มจากส่งแบบสำรวจใน Excel ให้ผู้ดูแลแต่ละ VM กรอกข้อมูล จากนั้นตรวจความครบถ้วน เทียบกับ tag ปัจจุบันใน Azure และสร้างแผนแก้ไขให้ตรวจทานก่อนลงมือจริง

## ข้อมูลในแบบสำรวจ

หนึ่งแถวใน Excel แทนหนึ่ง VM โดยใช้ `VM Name` และ `Resource Group` ระบุเครื่อง ข้อมูลสำหรับ tag หลักมี **4 รายการที่ต้องกรอก**:

| คอลัมน์ใน Excel | Azure tag | ตัวอย่างสมมติ |
| --- | --- | --- |
| Owner | `owner` | `owner@gmail.com` |
| Department | `department` | `Digital Enterprise System` |
| Environment | `environment` | `Production` |
| Project | `project` | `Customer Portal` |

`Server` เป็น tag เสริมที่เว้นว่างได้ ส่วน `Data Confirmed?` ใช้ค่า `Confirmed` หรือ `Pending` และ `Active VM?` ใช้ `Active`, `Inactive` หรือ `Unknown` ตัวอย่างในตารางเป็นเพียงภาพประกอบ; เมื่อนำไปใช้จริงต้องปรับค่าที่อนุญาต เช่น domain ของ Owner และรายชื่อ Department ให้ตรงกับองค์กร

## ขั้นตอนทำงาน

1. ตรวจแบบสำรวจ: สคริปต์ `01` ตรวจช่องว่าง รูปแบบ Owner และค่าที่กำหนดไว้ พร้อมสร้างรายงานให้แก้ข้อมูลที่ผิด
2. เทียบ Azure: สคริปต์ `02` อ่าน tag ปัจจุบันของ VM และแสดงจุดที่ขาด ชื่อ key ไม่ตรง หรือค่าไม่ตรงกับ Excel
3. ตรวจแผน: สคริปต์ `03` สร้างรายการ tag ที่จะเพิ่ม แก้ หรือลบ เพื่อให้ตรวจทานก่อนใช้งาน VM ที่ยัง `Pending` จะอยู่ใน `SKIP_VM` จึงคง tag เดิมและเพิ่ม `flag=Pending Owner Review`
4. ลงมือและย้อนกลับ: สคริปต์ `04` แสดง diff แบบ dry run ก่อน; การแก้ Azure ต้องสั่ง `--apply` โดยจะสำรอง tag เดิมไว้ หากจำเป็นใช้สคริปต์ `05` กับไฟล์สำรองเพื่อ rollback
